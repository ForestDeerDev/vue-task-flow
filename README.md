# Vue 任务管理系统

一个基于 Vue 3 + Vite 的任务管理课程作业，使用 Composition API、`ref`、`reactive`、`computed`、`v-model`、`v-for`、`v-if / v-else` 和事件修饰符实现任务管理。

## 功能

- 新增任务：名称必填，支持分类、优先级、截止日期和备注。
- 任务列表：按优先级显示不同颜色；可以完成、编辑、删除任务。
- 搜索筛选：按名称关键词、分类、完成状态实时筛选。
- 清理任务：二次确认后批量清除已完成任务。
- 实时统计：任务总数、已完成/未完成数量及各分类分布。
- 响应式布局：适配桌面和手机屏幕。

## 运行方式

需要先安装 [Node.js](https://nodejs.org/)（建议使用当前 LTS 版本）。在项目根目录执行：

```bash
npm install
npm run dev
```

终端会显示本地开发地址，使用浏览器打开即可。

构建生产版本：

```bash
npm run build
```

## 关键知识点

- `v-for`：循环渲染分类、优先级选项、任务卡片和统计分类。
- `v-model`：双向绑定表单、搜索框、筛选条件和任务完成复选框；搜索使用 `.trim`。
- `v-if / v-else`：控制空结果提示；`v-if` 也用于编辑态和清除确认弹窗。
- `@submit.prevent`：阻止表单提交刷新页面。
- `@click.stop`：阻止“清除已完成”按钮的点击事件向上冒泡。
- `computed`：根据任务数据实时计算筛选结果和统计数据。

> 当前示例任务存放在内存中，刷新页面后会恢复示例数据；如需持久化，可进一步添加 `localStorage`。
